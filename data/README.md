This directory is the documented home for input datasets used by the publication-facing scripts.

Recommended contents:
- raw archives such as `rnastralign.csv`
- dataset file lists such as `converted/RNAStrAlign8_dataA_train.h5`, `converted/RNAStrAlign8_dataA_valid.h5`, `converted/RNAStrAlign8_dataA_test.h5`, and `converted/Archive8.h5`

The used versions of RNAStrAlign and ArchiveII, are from Hugging Face and can be found [here](https://huggingface.co/datasets/multimolecule/rnastralign) and [here](https://huggingface.co/datasets/multimolecule/archiveii)

Intermediate files that are large can be found [here](https://drive.google.com/drive/folders/15VAdY8AYT4Z6OosgDE6-HZ-c1UZ5YQeW?usp=sharing)
