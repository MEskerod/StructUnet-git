This directory is the documented home for input datasets used by the publication-facing scripts.

Recommended contents:
- raw archives such as `RNAStralign.tar.gz`
- converted per-sample pickle directories
- dataset file lists such as `train.pkl`, `valid.pkl`, `test.pkl`, and `archive.pkl`

Gzip-compressed tar achives of RNAStrAlign data set and the converted datasets can be found [here](https://drive.google.com/drive/folders/15VAdY8AYT4Z6OosgDE6-HZ-c1UZ5YQeW?usp=sharing)
